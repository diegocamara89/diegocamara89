# Diego Câmara

IA aplicada à investigação e à segurança pública. Ensino policiais a usar inteligência artificial com rigor e construo ferramentas abertas para agentes de IA (Claude Code, Gemini, Codex).

A regra que guia tudo aqui: **resposta de IA é candidata, não prova.** Toda saída é hipótese até alguém conferir na fonte.

## IA e agentes

| Projeto | O que faz |
|---|---|
| [claude-mods](https://github.com/diegocamara89/claude-mods) | Mods do Claude Code: revisão com prova, painel ao vivo, lixeira e varredura de segredos antes do push |
| [llm-council](https://github.com/diegocamara89/llm-council) | Uma pergunta respondida por vários modelos, com revisão anônima entre eles e síntese final |
| [agent-skills](https://github.com/diegocamara89/agent-skills) | Orquestração de várias IAs por linha de comando (Gemini, Codex, Qwen, Claude) |
| [call-agy](https://github.com/diegocamara89/call-agy) | Chamada confiável da CLI Antigravity (Gemini) a partir de scripts no Windows |
| [avaliar-ferramenta](https://github.com/diegocamara89/avaliar-ferramenta) | Avalia skills, plugins e servidores MCP antes de instalar |
| [claude-skill-transcrever-video](https://github.com/diegocamara89/claude-skill-transcrever-video) | Baixa e transcreve vídeo no próprio computador (yt-dlp + faster-whisper) |
| [html-handoff](https://github.com/diegocamara89/html-handoff) | Documentos longos em HTML navegável em vez de texto corrido |
| [claude-go](https://github.com/diegocamara89/claude-go) | Envio agendado de mensagens para a sessão do Claude Code |
